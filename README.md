# 3D 华容道

将红色积木送到绿色目标，让所有蓝色积木从出口离开。灰块可按其方向限制移动，深灰块是固定墙体；红块离开房间会失败。

## 运行与检查

需要 Node.js 24.13 或更新版本。

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install
npm run test:browser
```

浏览器测试覆盖 Chromium、Firefox、WebKit；原生多指事件与强制 WebGL 丢失/恢复使用 Chromium CDP，仅在 Chromium 项目执行。浏览器截图和失败 trace 保存在忽略的 `test-results/`。

## 操作

- 点击积木选择，再点击一个面，沿该面的外法线移动一格。箭头是允许移动方向的标记；六向自由块保持无箭头。
- 同一个平面上的相邻格面使用连续箭头，真实凹口、台阶和棱边不会被错误跨越。
- Shift + 点击或“滑动到底”会沿同一规则移动至阻挡，或直到最后一个单元格离开房间。
- 方向按钮提供触屏和键盘可访问的移动入口；被规则或碰撞禁止的方向不可点击。
- 拖动旋转，中键平移，滚轮缩放；触屏双指缩放/平移。
- 点击空白或 Esc 取消选择；复位视角恢复完整取景；重新开始可中断当前动画并恢复关卡。

## 实现约定

关卡在 `src/data.ts` 中定义。`LEVEL_VIEW.allowInteriorView` 为 `true` 时允许相机进入房间；为 `false` 时（当前配置），滚轮缩放、旋转和平移会在首次接触房间边界时停止，不会弹回或强制拉远。受阻后反向操作立即生效。

- `space.ts` 统一六面坐标、出口集合、方向和输入校验。
- `logic.ts` 对关卡深拷贝，公共移动命令逐格验证完整体素，拒绝非法、跨轴、小数与超出合法距离的提交。
- `surfaces.ts` 提取同平面连通区域，生成恒定世界宽度的矢量箭头笔画。箭头尖只出现在允许方向的区域边界。
- `blockRenderer.ts` 用顶点色合并六面绘制，反馈不会影响其他积木。绿色目标线区分可见与被遮挡部分。
- `wallRenderer.ts` 按墙面合并几何，真实开孔共用逻辑定义。出口采用外置、穿过有效开口且带阴影的聚光照明；剖视墙接收主光阴影，不把外部主光封死。
- `wallMaterial.ts` 统一固定块和背景墙的颜色、格纹与材质；`lighting.ts` 本地生成环境照明，并在 WebGL 上下文恢复后重建。
- 房间外框棱边以低对比度虚线显示；线在容器外侧并遵守正常深度遮挡，因此只在墙体开口等空处可见，不会穿过积木或墙面。
- `navigation.ts` 在提交相机位置前限制完整运动路径，包括快速旋转时的中间圆弧；剖视墙显示方式与相机进入权限分别处理。
- 后处理为线性场景 → Bloom → OutputPass（ACES / sRGB）→ FXAA；场景 render target 使用 4× MSAA。DPR 与后处理同步，最大 DPR 1.75 / 约 200 万像素。
- 渲染只在相机、输入、状态、尺寸或动画变化时执行；静止场景复用阴影。退出、重开和销毁时释放资源。
- `tests/` 包含审计反例、18,000 组独立规则对照、表面连续性/方向约束、资源释放、手势和完整浏览器流程。

具体缺陷对应关系见 [修复记录](docs/修复记录.md)。
